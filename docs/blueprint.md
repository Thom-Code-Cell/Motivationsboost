# **App Name**: MotivationsBoost

## Core Features:

- Motivation Style Selection: Allows the user to choose the tone that will be applied to the generated cover letter.
- AI-Powered Cover Letter Generation: Generates a cover letter based on the provided job URL and the chosen motivation style, leveraging the Gemini API through a cloud function to tailor the letter to the job description.
- Job Link Input: Provides an interface where users can paste a URL of a job advertisement to initiate the generation process.
- Dashboard: Provides access to basic functionality.

## Style Guidelines:

- Primary color: Deep saffron (#FF9933), evoking ambition and warmth.
- Background color: Pale peach (#FAEBD7), offering a soft and inviting backdrop.
- Accent color: Burnt orange (#CC6633), drawing the user's attention.
- Body and headline font: 'Inter' (sans-serif) for a clean, modern, and readable experience.
- Minimalist line icons to represent different sections of the app (upload, generate, feedback, etc.).
- Mobile-optimized design with clear tab navigation.
- Subtle transitions and loading animations.
